Legacy sequential lifecycle scripts (pre-revision; NOT used for the reported results)

Note: these scripts follow an Ethereum RPC flow (ethers v6). The results reported in the
manuscript come exclusively from scripts/benchmark-final/benchmark_final.ts (results/final/).

0) One-time setup
0.1 Install packages
npm i ethers dotenv
npm i -D ts-node typescript @types/node

0.2 Create .env at the project root:

ETH_RPC=https://YOUR_RPC_URL
PRIVATE_KEY=0xYOUR_PRIVATE_KEY
ETH_CONTRACT_TEST=0xYOUR_NFTCOWCERTV2_CONTRACT

# mint target address (defaults to signer.address if omitted)
MINT_TO=0xRECIPIENT_ADDRESS

# transfer goes MINT_TO -> TRANSFER_TO (defaults to signer.address if TRANSFER_TO is omitted)
TRANSFER_TO=0xTARGET_ADDRESS

0.3 Required input files

./output/cid_list.json (from the IPFS upload step)
./artifacts/contracts/NFTCowCert_v2.sol/NFTCowCert.json (ABI)

Output files (written to ./output/):

01_mint_results.json
02_transfer_results.json
03_block_results.json
04_unblock_results.json
05_fetch_results.json
plus failed_*.json for later inspection/retry

01_mint.ts  - issue certificates from cid_list.json
  reads output/cid_list.json; calls issueCert(to, cid, cowId, cowHash);
  parses Transfer(0x0, to, tokenId) to obtain tokenId; failures are logged without stopping.
  run: npx ts-node 01_mint.ts

02_transfer.ts - transfer successfully minted tokens
  reads output/01_mint_results.json; selects status="success" with tokenId;
  calls safeTransferFrom(MINT_TO -> TRANSFER_TO, tokenId); failures are logged separately.
  run: npx ts-node 02_transfer.ts

03_block.ts - block successfully minted tokens (blockCert(tokenId))
  run: npx ts-node 03_block.ts

04_unblock.ts - unblock successfully minted tokens
  run: npx ts-node 04_unblock.ts

05_fetch.ts - read certs(tokenId) and record metadataCID, isBlocked, id (read latency)
  run: npx ts-node 05_fetch.ts

Execution order: 01_mint -> 02_transfer -> 03_block -> 04_unblock -> 05_fetch
